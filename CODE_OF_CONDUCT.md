# Code of Conduct

## Our standard

This project aims to provide a welcoming, constructive environment for everyone who participates.

Examples of positive behavior include:

- being respectful when discussing ideas, bugs, code, and design decisions;
- giving useful, specific feedback;
- accepting that contributors may have different levels of experience;
- focusing criticism on the work rather than the person;
- respecting reasonable boundaries set by maintainers.

Unacceptable behavior includes harassment, discrimination, personal attacks, deliberate disruption, publishing another person's private information without permission, or other conduct that would reasonably make participation unsafe or hostile.

## Scope

This code of conduct applies to project spaces, including issues, pull requests, discussions, and other public interactions made on behalf of the project.

## Enforcement

Project maintainers may edit, remove, reject, or lock contributions and interactions that violate these standards. Repeated or serious violations may result in temporary or permanent exclusion from project spaces.

If you need to report conduct privately, use the maintainer contact method listed on the GitHub profile rather than opening a public issue.

## Attribution

This code of conduct is intentionally short and project-specific. It is inspired by common open-source community standards, including the Contributor Covenant.
